# Peminjaman Kit Kelas FILKOM

Prototype aplikasi peminjaman dan pengembalian Kit Kelas menggunakan HTML,
CSS, dan JavaScript tanpa framework.

## Struktur proyek

```text
Peminjaman-Kit-Kelas/
├── index.html      # Kerangka halaman dan urutan pemuatan file
├── css/
│   └── style.css   # Gaya visual dan responsivitas
└── js/
    ├── data.js     # Data contoh ruangan dan peminjaman
    └── script.js   # Tampilan, alur aplikasi, dan interaksi
```

## Menjalankan aplikasi

Buka `index.html` langsung di browser atau gunakan Live Server di VS Code.
Masuk dengan akun apa saja untuk menjadi peminjam; gunakan `petugas` sebagai
akun untuk membuka menu petugas. Data demo hanya tersimpan selama halaman
terbuka dan akan kembali ke kondisi awal setelah dimuat ulang.
